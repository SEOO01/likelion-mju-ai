# 8주차 스터디 감상문

- 이름: 박서준
- 시청 영상: https://youtu.be/c88oWQfeo3Q?si=tuBQQ5oTJLOWu4tj

## 1. 인상 깊었던 내용

영상을 보며 가장 인상 깊었던 내용은 마지막 부분이었다. 비행기 회사를 예시로 다른 회사보다 10배 안전한건 가능하지만 사고가 전혀 없을 것이라는 것에는 대답하지 못한다라는 말이 잘은 모르겠지만 가장 기억에 남는 것 같다.

## 2. 새롭게 알게 된 점

이번 영상을 통해 새롭게 알게 된 점은 모델들이 취약점을 잘 찾는다는 것이다.또한 엔트로픽의 클로드를 펜타곤에서 ai 기술 전면 사용을 요청했다는 부분이있다 .군사적으로 ai를 사용할 것이라 생각했는데 좀 더 직접적으로 사용되고 있는 것 같다. 군 관련 내용에서 최종 결정은 언제나 사람이 내린다는 부분을 강조하는데 ai는 보조 장치라는 부분이 기억에 남는다.

## 3. 느낀 점

영상을 보면서 느낀 점은 생각했던 직업이 생각 이상으로 빠르게 변하고 있고 나도 그에 맞춰 가야할 것이라는 부분이다. 영상 중간에 몇몇 회사는 ai에 적응하지 못하면 망하거나 큰 손해를 볼 수 있을 것이라고 말했는데 그게 기업만을 대상으로 하는 말은 아닌 것 같다. 취업을 기본으로 생각하는 대학생들이 ai에 적응하지 못 한다면 큰 손해를 볼 수 있을 것 같다. 아직 컴퓨터 공학에서도 어떤 분야를 갈지 생각해보면 좋을 것 같다.

## 4. 스터디 또는 프로젝트에 적용해보고 싶은 점

현재 스터디 내용이나 앞으로의 프로젝트에 연결해서 생각해볼 수 있는 부분은 아직 잘 모르겠다. 프로젝트에 연결할 수 있는 부분 보다는 ai로 인해 계속 바뀌는 미래에 내가 ai로 어떤 일을 할 수 있을지 좀 더 생각해보는 것이 필요할 것 같다.
